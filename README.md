# تصحیح‌یار (نسخه ۲)

ابزار بازبینی دبیر برای نتایج تصحیح هوش مصنوعی (جمینای / Claude).

## روش کار
1. اوراق را با پرامپت تصحیح‌یار در جمینای یا Claude تصحیح کنید. در پایان هر برگه یک بلوک JSON می‌گیرید.
2. در برنامه، تب «ورود نتایج»، متن خروجی را بچسبانید (چند دانش‌آموز را یک‌جا می‌شود).
3. تب «بازبینی دبیر»: متن عینی دانش‌آموز، نمره‌ی پیشنهادی مدل و ستون «نمره نهایی» را می‌بینید و نمره‌ی نهایی را خودتان می‌نویسید. جمع نمره با کد محاسبه می‌شود.
4. اگر PDF اسکن را در نوار کناری بارگذاری کنید، تصویر برگه کنار جدول نمایش داده می‌شود.
5. تب «خلاصه و خروجی»: جدول کلاسی و جزئیات (Excel) و گزارش دانش‌آموزان (Word).

## نکته‌ها
- داده‌ها فقط در حافظه‌ی نشست می‌مانند. از «ذخیره‌ی پروژه» در نوار کناری استفاده کنید.
- برای تست، فایل `sample_student.json` را بچسبانید.

## اجرا
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Start Command در Render
```
streamlit run app.py --server.port $PORT --server.address 0.0.0.0 --server.headless true --server.enableCORS false --server.enableXsrfProtection false
```
