# تصحیح‌یار | سامانه تصحیح اوراق امتحانی

سامانه تخصصی تصحیح خودکار اوراق امتحانی جامعه‌شناسی ۳

## اجرا با Streamlit

```bash
streamlit run app.py
```

## استقرار رایگان روی Streamlit Cloud

1. این مخزن را Fork یا آپلود کنید.
2. به [share.streamlit.io](https://share.streamlit.io) بروید.
3. New app → این مخزن را انتخاب کنید.
4. Main file path: `app.py`
5. Deploy!
